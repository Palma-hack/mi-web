Arquitectura de Comunicación IoT & Fibra Óptica

Distribución jerárquica en 4 niveles desde los dispositivos de campo hasta las plataformas Cloud

Nivel 1: Campo
Sensores de campo (MQ-2, PIR HC-SR501, Flotador Magnético Eicos LA36M-40) y actuadores (Bomba 120V TRUPER, Contactor KM1, Sirena Local, Luminarias LED).
Nivel 2: Control
Microcontroladores ESP32 Dev Module (Procesamiento analógico/digital y WiFi local) + PLC Siemens LOGO! 8.3 (Lógica industrial de autorretención FBD).
Nivel 3: Conectividad
Enlace FTTH GPON (Claro Nicaragua) desde Estación Base Sabana Grande (~1.8km), ONT Residencial, Broker MQTT Mosquitto local y communication Ethernet Modbus TCP / S7.
Nivel 4: Gestión Cloud
Servidor de integración Node-RED con Dashboard 2.0, ThingsBoard Cloud para almacenamiento de telemetría y alertas push a Gmail / WhatsApp.

Especificaciones de Equipamiento Principal

Dispositivo Especificaciones Técnicas Principales Protocolo / Interfaz Función en el Prototipo
Siemens LOGO! 8.3 12/24V DC, 8 ED (4 AI 0-10V), 4 Salidas Relé 10A, Display LCD. Ethernet (Modbus TCP / S7) Control automático de bomba y enclavamiento de seguridad.
ESP32 Dev Module Xtensa Dual-Core 32-bit, 240MHz, 520KB SRAM, Wi-Fi 2.4GHz + BT. Wi-Fi / MQTT / HTTP Adquisición de sensores MQ-2/PIR y transmisión IoT.
Sensor MQ-2 Semiconductor SnO2, rango 300-10,000 ppm (GLP, metano, humo). Analógica (0-5V) / Digital Detección temprana de fugas de gas en cocina.
Eicos LA36M-40 Flotador magnético lateral, contacto Reed Switch discreto ON/OFF. Entrada Digital (I4 PLC) Corte automático por nivel máximo en el tanque.
Infraestructura GPON Acometida Drop Monomodo G.657.A, ONT FTTH SC/APC. Fibra Óptica FTTH Enlace de alta velocidad con la Estación Base Sabana Grande.
